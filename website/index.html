Updates without a reflash

AetherPatch layers signed component updates over the read-only base — on a live USB or an installed disk.

Layered modules

Component squashfs

live-boot unions every /live/*.squashfs in order. A patch is a small new layer dropped onto the stick — the base image never changes.

Atomic

Boot-in, boot-out

Each update activates on next boot. A bad patch? Delete one file — the previous system is untouched underneath. Zero-risk rollback.

Signed

Ed25519 channel

aether-update check · apply · rollback pulls a signed channel manifest, verifies every module, then installs. Same plumbing for installed systems via apt.

FAQ

The things everyone asks first.

Why is the latest build 2.2 GB when the release was 2.9 GB?

The v1.0.0 release froze an earlier, heavier build (shipped as two 2 GiB-capped parts). The current CI build is the same OS after post-release trimming — the artifact ZIP (~2.25 GB) is exactly the ISO (2.26 GB) plus its checksums. Nothing is missing; newer is just leaner.

Do I really not need to flash the USB stick?

Correct. Ventoy installs once on the stick; after that ISOs are plain files you copy onto it. No dd, no Rufus, no overwriting — and several distros can coexist on one stick.

Does the live session touch my hard drive?

No. The system runs from RAM and the USB stick. Installing to disk is an explicit choice from the desktop installer.

What are the minimum specs?

64-bit CPU, 4 GB RAM for the live desktop, UEFI or legacy BIOS boot, any USB port. The CI job smoke-boots every build under QEMU before publishing the artifact.
